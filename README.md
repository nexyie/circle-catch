HOW THE GAME WORKS!

a dot goes around a circle, click when it hits the green part. dont miss or you start over

how to play

just open index.html in your browser lol

click the circle (or press space) to start
click again when the ball hits the green bit
miss and your score goes back to 0
gets faster the more you get

your best score is saved so you can flex on yourself later

running it

no install or anything needed, just open the html file. or use github pages if you want a link
